マルヒデ砂王 プライバシーポリシー

制定日：2026年9月22日

マルヒデ事業部（以下「当方」）は、Android および iOS 向けアプリ「マルヒデ砂王」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 当方が直接取得する情報

当方は、利用者を識別できる情報を一切取得しません。本アプリは会員登録もログインも必要としません。

得点・消した段・連続消し・全消しの記録は、利用者の端末内にのみ保存されます。当方のサーバーへ送信されることはありません。アプリを削除すると、これらの記録も端末から消えます。

2. 広告の配信について

本アプリは、Google が提供する広告配信サービス「Google AdMob」を利用しています。AdMob は広告の配信のために、次の情報を取得することがあります。

  • 広告識別子
  • おおよその位置情報（IPアドレスに基づく国・地域程度）
  • アプリの利用状況

これらは、広告の配信・配信効果の測定・不正防止のために利用されます。取得された情報の取り扱いは、Google のプライバシーポリシーに従います。

広告のパーソナライズは、端末の設定から無効にできます。

  • Android：設定 → Google → 広告 → 広告 ID を削除
  • iOS：設定 → プライバシーとセキュリティ → トラッキング

Google のポリシー：https://policies.google.com/technologies/ads?hl=ja

欧州経済領域等にお住まいの利用者には、初回起動時に同意の確認画面（Google の User Messaging Platform）が表示されることがあります。

3. 通信について

本アプリが通信を行うのは広告の取得のためだけです。ゲームの進行や記録の保存に通信は使いません。オフラインでも遊べます（その場合、広告は表示されません）。

4. 第三者への提供

当方が利用者の情報を第三者に販売・提供することはありません。広告配信事業者が取得する情報は、当該事業者のポリシーに基づいて取り扱われます。

5. 子どもの利用について

本アプリは13歳未満の方を対象として設計したものではありません。当方が意図して13歳未満の方の情報を収集することはありません。

6. 本ポリシーの変更

本ポリシーは変更されることがあります。変更した場合は、本ページに掲載します。
